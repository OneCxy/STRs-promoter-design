# ProSTR
ProSTR is a two-stage framework for designing high-activity promoters by incorporating STR priors.<br>
In the first stage, TFBS elements and STR patterns are combined to form a core scaffold, and candidates with reasonable structures are selected.<br>
In the second stage, the upstream and downstream regions are generated based on the fixed scaffold to obtain full-length promoter sequences, while maintaining structural consistency.<br>
Finally, an independently trained activity predictor is used to score and rank the generated sequences, and high-potential candidates are selected.<br>
This “structure-first, then generation” strategy makes the process more controllable and improves both efficiency and stability.<br>

# Design Promoter Sequence
We take design promoters in E.coli as an example,to illustrate how to train the ProSTR model and design the promoter sequences.

## 1. Training the predictor (can be done in advance)

run \prediction\GRU.py <br>
This step trains the activity predictor.<br>
A pretrained predictor is needed before generation and reused as the scoring module in both stages. It scores candidates after STR insertion and flanking completion, selects high-activity sequences for stage-two refinement, and filters final outputs by predicted activity, yielding a consistent and stable selection process.<br>
>>Input:<br>
data/ecoli_prediction.csv <br>
Output:<br>
results/model/predictor.pth (trained model)<br>


## 2.Training the generator

* run \Generator\step1_cGAN.py <br>

Train the first-step conditional generator to learn the baseline sequence distribution and produce initial candidates.<br>
>>Input: <br>
data/ecoli_generation.csv <br>
(containing natural E. coli sequences, corresponding TFBS template strands, and their expression values) <br>
Output: <br>
cachetest/inducible_ecoli_*.csv  (the sequences in the "fakeB" column are generated by learning and sampling based on the TFBS template strands) <br>
cachetest/check_points/ecoli_net_G_last.pth  (generator) <br>
cachetest/check_points/ecoli_net_D_last.pth  (discriminator) <br>
cachetest/gen_iter_*.fasta <br>
cachetest/figure/* <br>


* run \Generator\str.py    <br>

Introduce and fill STR patterns in generated candidates to build an STR-enriched candidate set.<br>
>>Input: <br>
cachetest/inducible_ecoli_*.csv <br>
results/model/predictor.pth (trained model)  <br>
Output: <br>
cachetest1/fillseq_*.csv <br>
(each row contains: optimized sequence, corresponding template strand, predicted activity, <br>
original template, original sequence, update flag) <br>


* run \Generator\loss.py   <br>

Compute similarity loss between generated and natural sequences for quality-aware filtering.<br>
>>Input:  <br>
cachetest1/fillseq_*.csv  (STR-modified sequences)  <br>
data/ecoli_generation.csv  (natural sequences used as reference)  <br>
Output:  <br>
cachetest1/fillseq_*_with_loss.csv  (each sequence with an added loss value)  <br>
cachetest1/fillseq_*_with_loss_sort.csv  (sorted by loss)  <br>
cachetest1/fillseq_*_with_loss_sort1.csv  (sorted sequences only)  <br>
cachetest1/fillseq_*_with_loss_sort.fasta  (converted to FASTA format)  <br>
cachetest1/fillseq_*_with_loss_tiqu.csv  (final selected sequences used for the next stage)  <br>

* run \Generator\step2_cGAN.py <br>

Train the second-step generator on the filtered set to further improve sequence quality and functional characteristics.<br>
>>Input:<br>
cachetest1/fillseq_*_with_loss_tiqu.csv (filtered sequences after loss-based selection) <br>
Output:<br>
cachetest2/inducible_fillseq_tiqu_*.csv  (generated sequences)<br>
cachetest2/gen_/iter_*.fasta (FASTA format sequences)<br>
cachetest2/figure/* (k-mer analysis results)<br>
cachetest2/training_log/* (training logs)<br>
check_pointstest2/fillseq_tiqu_net_G_last.pth (generator)<br>
check_pointstest2/fillseq_tiqu_net_D_last.pth (discriminator)<br>

* run \prediction\GRU.py  <br>
Run prediction/GRU.py again to predict activity values for the generated sequences and perform selection.
>>Input:<br>
data/ecoli_prediction.csv <br>
cachetest2/inducible_fillseq_tiqu_*.csv  (generated sequences for inference)<br>
Output:<br>
results/val_predictions.csv (predicted activity values for generated sequences)<br>
